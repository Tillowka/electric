# Обновления панели управления

## Что добавлено
- Отдельная страница `/manage/<id>/photos/add/` для загрузки нескольких фотографий за один раз.
- На странице загрузки новых фото старые фотографии не отображаются.
- На странице изменения объекта показываются существующие фото; можно удалить фото или изменить подпись/порядок, но загрузка новых фото вынесена на отдельную страницу.
- Страница `/manage/stats/` со счётчиками объектов, фотографий, всех пользователей, активных учётных записей, администраторов и пользователей с действующей сессией.
- Адаптивные стили для телефонов и планшетов.

## Запуск на Windows
В папке проекта активируйте виртуальное окружение, затем выполните:

```bat
.env\Scripts\activate
py -m pip install -r requirements.txt
py manage.py check
py manage.py migrate
py manage.py runserver
```

Новые модели и миграции не добавлялись, поэтому `makemigrations` не требуется. Все новые страницы доступны только вошедшим сотрудникам (`is_staff=True`).

Статистика «Пользователи с действующей сессией» отражает активные сессии авторизации в базе Django и не является точным измерением людей, находящихся на сайте в эту секунду.


## Дополнительно: подписи и статистика посетителей
- При загрузке нескольких фотографий появляются отдельные необязательные поля описания для каждой фотографии.
- Страница статистики содержит вертикальную диаграмму в стиле сайта.
- Добавлен подсчёт посетителей по браузерным сессиям: «сейчас на сайте» — активность за последние 2 минуты, счётчик обновляется каждые 30 секунд; «всего посетителей» хранится в базе.
- Для создания таблицы статистики после обновления проекта выполните `py manage.py migrate`.
- Онлайн-показатель означает активные браузерные сессии, а не подтверждённое число уникальных людей. IP-адреса не сохраняются.
