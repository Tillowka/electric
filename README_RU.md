# Сайт-портфолио электрика (Django)

## Возможности
- Главная страница с информацией о специалисте, услугах и карточками выполненных объектов.
- Отдельная страница каждого объекта с обложкой, описанием и фотогалереей.
- Защищённая панель `/manage/`: просмотр объектов, редактирование, удаление и массовое создание.
- При редактировании объекта можно добавлять и удалять фотографии. Удаление объекта удаляет связанные записи фотографий и сами файлы.
- Кнопка «Войти» в шапке ведёт на страницу входа. После входа пользователя со статусом staff/superuser она меняется на «Управление».
- CSRF-защита форм, доступ к панели только для staff-пользователей и настраиваемые параметры безопасности.
- Адаптивный дизайн, SQLite для локального запуска, загруженные изображения хранятся в `media/`.

## Запуск в Windows
1. Распакуйте ZIP и откройте папку `electrician_portfolio` в терминале.
2. Создайте окружение и активируйте его:
   ```powershell
   py -m venv .env
   .\.env\Scripts\Activate.ps1
   ```
3. Установите зависимости:
   ```powershell
   python -m pip install -r requirements.txt
   ```
4. Создайте таблицы базы данных:
   ```powershell
   python manage.py makemigrations works
   python manage.py migrate
   ```
5. Создайте администратора:
   ```powershell
   python manage.py createsuperuser
   ```
6. Запустите сайт:
   ```powershell
   python manage.py runserver
   ```
7. Откройте `http://127.0.0.1:8000/`, затем нажмите «Войти» или откройте `http://127.0.0.1:8000/login/`.
8. После входа перейдите в «Управление» или откройте `http://127.0.0.1:8000/manage/`.

## Управление объектами
- `/manage/` — список объектов, кнопки «Изменить» и «Удалить».
- `/manage/create/` — создание сразу нескольких объектов; кнопка «Ещё объект» добавляет дополнительные формы.
- На странице редактирования можно менять поля объекта, загружать новые фотографии и отмечать ненужные фотографии для удаления.
- Удаление объекта необратимо: оно удаляет объект и связанные фотографии из базы и файлового хранилища.

## Перед публикацией в интернете
- Задайте длинный случайный `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=False` и корректный `DJANGO_ALLOWED_HOSTS`.
- Настройте HTTPS до включения `DJANGO_SECURE_SSL_REDIRECT=True` и `DJANGO_COOKIE_SECURE=True`.
- Настройте резервное копирование базы данных и папки `media/`; регулярно обновляйте зависимости.
